01Project overview

AutoVault is a car dealership website built with the Next.js App Router. It includes eight homepage designs, vehicle listings, car details, dealers, articles, a shop, a loan calculator, a cart and saved cars.

Native Next.js pages

Editable TSX components, shared sections and clean application URLs. The app does not parse or embed the source template's HTML.

Original template styling

Bootstrap, the original CSS, local fonts and image assets. Tailwind is not installed.

The application lives in src/, and its static assets live in public/assets/. This standalone guide lives in public/documentation/index.html, served at /documentation/index.html alongside the standalone landing page at /landing/index.html.

02Installation & local development

Install Node.js 20.9.0 or newer and npm. Run commands from the project root, the folder containing package.json. 

cd D:\projects\projects_2026\autovault-nextJS
npm ci
npm run dev

Open http://localhost:3000. The development server updates pages as you edit components and styles. An initial environment file is not required for the current template features.

Windows PowerShell: if execution policy blocks npm scripts, use npm.cmd ci, npm.cmd run dev and npx.cmd in place of npx.

Use npm ci for a clean installation from the committed lockfile. After deliberately changing dependencies with npm install, commit both package.json and package-lock.json.

05Slug-based detail pages

Detail records are stored in src/data/detail-catalog.json. The catalog currently contains 8 cars, 16 articles, 9 dealers and 10 products.

Content Canonical route Catalog key
Car, first layout /car/[slug] car
Car, second layout /car-two/[slug] car
Article /blog/[slug] blog
Dealer /dealer/[slug] dealer
Product /product/[slug] product

Edit or add a record

  1. Find a record of the same kind in the catalog and copy its complete field structure.
  2. Choose a unique, lowercase, hyphen-separated slug. Keep the object key and the record's slug identical, and preserve its kind.
  3. Update titles, descriptions, prices, specifications, image URLs and galleries. Place new assets under public/assets/.
  4. Update the corresponding listing cards and related links in the relevant section components; listings are not generated automatically from the catalog.
  5. Run project verification and a production build. Check the record's page, metadata, gallery and related links.

Use the shared helper to keep links consistent:

import { detailPath } from "@/lib/detail-paths";

detailPath("car", "thunderbolt-car");
// /car/thunderbolt-car

detailPath("car", "thunderbolt-car", true);
// /car-two/thunderbolt-car

Record-specific metadata and static parameters are generated by the detail routes. Legacy detail URLs redirect to the canonical routes. Default records are configured in src/data/detail-defaults.json; unknown slugs return HTTP 404 through validation in src/proxy.ts.

Keep URL-dependent work inside Suspense. Detail pages await params inside the suspended detail component. Keep the shared DetailShell independent of URL data to preserve instant navigation.

06Customize the design & content

Change Where to edit
Text, page sections & listing cards Route composition in src/app/ and sections in src/components/sections/
Logo, header links & footer content The relevant Header*.tsx and *Footer.tsx section components
Images & local fonts public/assets/; keep URL filename capitalization exact
Original theme rules public/assets/css/style.css and the retained SCSS sources
Custom CSS & animation overrides src/app/globals.css
Default title, description & favicon src/app/layout.tsx; detail routes also supply record-specific metadata

The original theme uses --color-primary: #FF3600 and the Outfit font. Add focused overrides in globals.css; use selectors with enough specificity to override the linked theme stylesheet. Shared sections may appear on several routes, so check the affected layouts after editing them.

Template regeneration

scripts/convert-template.mjs records the original migration from the sibling HTML project. Normal development and production builds do not run it. Intentional regeneration with node scripts/convert-template.mjs ../autovault overwrites generated routes and sections, so preserve custom edits first. The conversion also applies detail-route and AOS migrations.

07AOS & the move-right animation

Scroll reveals use AOS in place of WOW. Add data-aos attributes directly to JSX. Delay and duration values are expressed in milliseconds; AOS's supplied styles support 50 ms steps up to 3000 ms. 

<div
  data-aos="fade-up"
  data-aos-delay="100"
  data-aos-duration="1000"
>
  Your content
</div>

<h2 className="section-title move-right" data-aos="move-right">
  Your section heading
</h2>

The custom move-right class reveals content from left to right with a CSS clip transition. Both the class and data-aos="move-right" are required. Its rules live in src/app/globals.css.

src/lib/animations.ts initializes AOS once, with a 1000 ms default duration, ease-out-cubic easing, a 60 px offset and one-time reveals. It refreshes for route content, image loads and fonts. Reduced-motion styles keep content readable without movement, and server-rendered content remains visible before AOS initializes.

scripts/migrate-animations.mjs converts legacy reveal attributes when regenerating template sections. Edit the current TSX attributes directly for day-to-day changes.

08Sliders, scrolling & plugins

Integration Behavior & source
Swiper Options in src/lib/sliders.ts; initialization in PageEffects.tsx. Controls are scoped to their page section. Car gallery arrows select the main image, and the Thumbs module updates swiper-slide-thumb-active.
Lenis src/components/SmoothScroll.tsx provides smooth wheel scrolling, hash anchors and sticky-header offsets. Back-to-top uses src/lib/smooth-scroll.ts. Native touch and nested control scrolling are retained; smoothing is disabled for reduced motion.
Jarallax src/lib/parallax.ts provides desktop background parallax. Mobile and reduced-motion layouts use static backgrounds.
Nice Select src/lib/nice-select.ts enhances native selects using jQuery 3 and the original dropdown design, synchronizing selection, keyboard interaction and form values.
Bootstrap Layout styles are loaded globally. Tab and collapse interactions initialize within page effects.
Sticky footer src/lib/sticky-footer.ts preserves dim-fixed and dim-static behavior on desktop and resets it on mobile. Footer space is measured dynamically.

Keep route-specific integrations inside the page lifecycle. Register cleanup when adding event listeners, observers or plugin instances so cached navigation does not create duplicate handlers.

09Forms, calculator, cart & saved cars

  • Loan calculator: supports loan terms, down payments, interest and zero-interest calculations. The shared calculation logic lives in src/lib/.
  • Cart: quantities, removals and totals use src/lib/cart.ts. Cart state persists in the current browser's local storage; checkout reads the same cart.
  • Saved cars: the wishlist uses src/lib/saved-cars.ts and browser storage. Saved-car links open the matching slug-based details.
  • Forms: contact, newsletter, account and checkout interfaces validate input. Authentication, email delivery and payment processing are not connected.

Backend scope: connect real services before accepting messages, user accounts or payments. The current template does not send mail, authenticate users or place orders. Browser storage is not a shared database.

10Quality checks

Command Purpose
npm run lint Check TypeScript/React source with ESLint.
npm run verify:project Validate route links, catalog records, asset paths and the application migration constraints.
npm run build Compile, type-check and generate the production build.
npm run test:e2e Run production browser tests against port 3100. Build first.
npm run test:dev Check development detail navigation for InstantServer/Suspense insights on port 3000.

Install the browser once with npx playwright install chromium. Run the browser suites sequentially because their default output directory is shared. The development test reuses a running development server when available. 

npm run lint
npm run verify:project
npm run build
npm run test:e2e
npm run test:dev

Browser checks cover routes, asset errors, navigation, dynamic records, gallery synchronization, AOS, reduced motion, smooth scrolling, footer behavior, plugins, cart, saved cars and forms.

11Production build & hosting

Use a hosting environment that supports the installed Next.js version and a Node.js runtime meeting its requirements. The project uses request Proxy behavior, dynamic routes and Cache Components; the current configuration is not a plain static HTML export. 

npm ci
npm run build
npm run start

npm run start serves the generated production build on port 3000 by default. Set the host's start command and port configuration as required by your deployment environment.

next.config.ts enables cacheComponents and partialPrefetching. Retain the existing Suspense boundaries when changing URL-dependent components. Check the installed documentation under node_modules/next/dist/docs/ before changing version-specific configuration.

Next.js serves the standalone pages from the public folder. Open /landing/index.html for the demo landing page and /documentation/index.html for this guide. Both pages and their local assets are included in the same deployment.

12Troubleshooting

PowerShell says npm.ps1 cannot run

Use the Windows executable commands npm.cmd and npx.cmd.

An image or font works locally but fails on the host

Check the exact filename capitalization and the /assets/ prefix. Run npm run verify:project to detect missing local asset references.

A new detail URL returns 404

Confirm the record exists under the correct catalog kind, with a matching key and slug. Check listing links and rebuild after editing the catalog.

Next.js reports URL data outside Suspense

Keep await params inside the suspended detail component. Use the existing DetailShell pattern rather than moving URL data into its shared static shell.

A gallery arrow does not update the selected image

Keep gallery arrows bound to the main Swiper instance. The thumbnail Swiper manages its strip, while the Thumbs module manages the selected thumbnail class. Verify both desktop and mobile layouts after changing options.

A move-right heading does not animate

Use both className="move-right" and data-aos="move-right". Confirm the AOS styles are imported and the page effects run. Reduced-motion preferences intentionally disable movement.

Mail, login or checkout does not submit to a service

These interfaces currently have no backend integration. Connect the appropriate service and implement server-side validation and error handling.

Playwright reports missing trace files

Run test:e2e and test:dev sequentially so they do not clean up each other's output files.
